# 保黎醫會報告

《保黎醫會報告》記錄浙江慈城保黎醫院癸丑年（1913）的院務成績、會計帳、捐助名錄、會務章程、院規及紀事。底本為中國國家圖書館 08jh011040／25506，掃描含封面、照片圖說、逐欄正文和逐格帳表，48 幅皆保留定位。

This fourth report of the Baoli Medical Association at Cicheng, Zhejiang, records the hospital’s 1913 activities through monthly statistics, accounts, donors’ and members’ names, bylaws, administrative rules and building captions. The catalog estimates publication in 1914. Every transcribed scan has a source locator.

- 原刊由保黎醫會編纂，刊次 約1914年（原刊題癸丑，報告1913年），浙江慈城。共 48 幅，依底本分幅定位。 [館藏／原件](https://commons.wikimedia.org/?curid=130965192)
